# Project_UI_Menu

Unreal Engine UI demo project.

## Unreal Version

Open with Unreal Engine 5.7.

## How To Open

1. Install Git LFS if using GitHub.
2. Clone or download this repository.
3. Open `Project_UI_Menu.uproject`.
4. If Unreal asks to rebuild modules, choose Yes.

## Main Test Map

`Content/UI/demo/L_UI_Demo.umap`

## Current UI Features

- Main menu with video background and UI sounds.
- Options secondary menu.
- Story secondary menu.
- Loading screen.
- Gameplay pause menu.
- Save/load UI demo.
- Reusable NPC dialogue system with branching nodes.

## Controls

- Mouse hover: highlight menu item.
- Click / Space: select.
- Esc / P: pause menu in gameplay.
- E: interact with demo NPC.

## Notes For Teammates

The project keeps source files, config, maps, UI assets, audio, and the main video background.
Generated folders such as `Binaries`, `Intermediate`, `DerivedDataCache`, and `Saved` are intentionally ignored because Unreal can regenerate them.
